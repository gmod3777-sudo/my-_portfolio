# Emon — Personal Developer Portfolio

A responsive personal portfolio website for Md. Al-Amin Hosen Emon, presenting his interests in AI/ML, full-stack development, and AI-assisted “vibe coding,” alongside his completed live project Wasifa Tours & Travels.

## Features
- Responsive desktop, tablet, and mobile layout
- Dark modern design with gradient accents
- About, AI/ML and development skills, projects, education, achievements, and contact sections
- Clear positioning as an aspiring AI/ML engineer, full-stack developer, and vibe coder
- GitHub profile link and live Wasifa Tours & Travels project
- Wasifa Tours & Travels featured as a completed live project
- Mobile navigation menu
- Scroll progress indicator
- Reveal-on-scroll animations and active section navigation
- Reduced-motion accessibility support
- No build tools or dependencies required

## Run locally
Open `index.html` in a browser. For a more realistic local server, use VS Code's Live Server extension.

## Before submitting
1. Verify your name and degree details.
2. Review your education details and make sure all skills accurately reflect your current experience.
3. Add an email address and any professional/social links you want to publish.
4. Add your real earlier education, verified certificates, and additional projects if applicable.
5. Only list technologies and contributions that accurately describe your work.
6. Optionally add a GitHub repository link for Wasifa Tours & Travels in its project card once its source code is public.

## Deploy with GitHub Pages
1. Create a new GitHub repository, for example `emon-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README (keep the same folder structure).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the Pages deployment to finish. The live address will appear on the Pages settings screen.
